## 🚀 What I'm Building

### Universal Task AI

A modular AI assistant designed to plan, execute, review, and deliver complex tasks across web and local environments.

**Core workflow**

```text
User Request
     ↓
Task Planning
     ↓
Execution Pipeline
     ↓
Web / Local / Search / Tools
     ↓
Review & Validation
     ↓
Final Result
```

The project focuses on:

- Security-first architecture
- Explicit task contracts
- Least-privilege execution
- Sandboxed execution
- Persistent run state
- Semantic memory
- Web UI and authenticated APIs
- External web search
- Production container hardening
- Automated testing and security checks
- Human approval for risky side effects
